What needs care.

Not every feature runs everywhere. An older runtime can load a new file while skipping unsupported features. Use the feature support table and verify the chosen runtime.

Performance is an integration job. Rive adds JavaScript/WASM and scene assets. Test image sizes, paths, clipping, simultaneous loops and mobile rendering. GPU Canvas is experimental and needs its own context per canvas; it is unnecessary for these website sketches.

Accessibility is not automatic. Web semantics are disabled by default and require authoring. Current docs also say semantic overlay elements are outside sequential Tab order. HTML remains the practical place for this site's navigation and forms.

This account exported both formats. A 14.9 KB .riv runtime file and an editable .rev backup were saved successfully. Direct macOS file access was blocked, and the tool’s documented byte-transfer fallback succeeded. Official docs and the tool still conflict about free-plan export entitlement; this account’s success does not establish entitlement for every plan. Official export documentation.

A good runner still needs animation craft. Clean silhouette, planted feet, knee motion, line quality and normal-speed playback matter. A successful state trace or a single PNG cannot prove those.
