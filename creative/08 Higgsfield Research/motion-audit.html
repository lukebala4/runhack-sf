Best use for this project

Higgsfield can make the visual world around Running Hackathon much stronger: a warm photographic hero in motion, expressive filmed mascot performances and sponsor films. Rive remains the right place for a small interactive character with precise cursor tracking, triggers, colour inputs and a game loop. Higgsfield's rendered clips are not exported Rive rigs, state machines or editable bone animation.

Three materially different routes:

Route Output and strongest fit Main limitation Recommendation
Reference image → Cinema Studio / Seedance video A short morning film: runner, brick-orange shoes, track becoming meadow, sunlit wind and understated sporting energy Generative motion and identity can drift; a seamless loop needs deliberate matching and editing First choice for the website hero and a launch film
Character sheet + driving performance → Genjutsu The chosen animal performing a human-recorded wave, jog, stretch or celebration; sponsor intro shorts Anatomy correspondence, hands, ears, tails and foot contact must be checked; output is flat video First choice for character acting experiments
Native Rive character driven by website code Fast reactions, live gaze, form feedback, sponsor colours and play-area mechanics Requires vector design/rig/animation work; Higgsfield cannot replace that authoring Keep this route for the actual interactive mascot

From scratch I would approve one character sheet, test one short native-looking performance and one photographic hero, then commit to the visual system. I would not generate all eight mascot states independently first: separate generations risk changing the character between states and cannot supply deterministic transitions.

Genjutsu: the useful distinction

The official Genjutsu page distinguishes motion transfer, which rebuilds a scene around the source motion, from object swap, which changes a selected element. Its published source-video window is 4–30 seconds and it advertises up to 30 reference images. These are product capabilities, not a guarantee of unchanged pixels or perfect character consistency.

The current preset browse returned these ranked examples among its first page: Stadium Orbit Rush, Athletic Dribble Swap and Jersey Detail Zoom. These are useful references for sporting camera language, but the high-energy ranking is not necessarily our aesthetic. I would choose a restrained owned jog/stretch take over a loud viral template.

The current complete Styles page returned 20 looks. Best matches to the user's request for real drawings and warmth:

  • Hand-Painted Cel Animation
  • Expressive 2D Animation
  • Graphic Cel
  • Textured Gouache Character Illustration
  • Warm Painterly 3D Animation
  • Felt Puppet Stop Motion, if we explore a deliberately tactile character

These redraw an existing video. They do not turn it into interactive vector art. Neither a catalog preview nor its example character should be reused as our subject reference.

Animal quality and consistency

The five existing animal directions are all plausible reference subjects, but none was tested here. A bipedal hare, fox or raccoon with clear human-like shoulders/hips is the most straightforward starting hypothesis for a human-driven performance. An otter's long torso and a deer's hooves/ears add mapping risks. This is an inference about anatomy, not a measured model ranking.

For a meaningful test, use one approved front/three-quarter/full-body sheet, consistent singlet and shoe colours, one uncluttered full-body take and a simple action. Compare face, silhouette, ear shape, tail, paw/hand count, shoe identity, planted feet, direction changes and first/last frames at normal playback speed. Only then expand to running or multi-shot acting.

Higgsfield's own character-quality guide says Kling 3.0 is oriented toward realistic humans and is a weaker fit for non-human or abstract subjects. That is vendor guidance, not an independent benchmark, but it is enough reason not to promise the current animal mascot will inherit perfect human lip sync or motion transfer.

No observed audio tool supplies streaming recognition, realtime dialogue memory, Rive viseme bindings or autonomous character decisions. Those need separate application code and a realtime service. For this website, silent-by-default plus optional short cues is a better initial fit than an always-speaking mascot.

Katana and advertised versus available

/use-video-editor and its verification reference explicitly identify Higgsfield Video Editor, a separate local plugin (higgsfield-video-editor-local, namespace higgsfield_video_editor_local). Its expected video_editing_open_project, create, outline, edit, preview and render tools are absent in the tool inventory of this chat. No setup or installation was attempted. A main Higgsfield connector, localhost page, or successful generation does not establish access to that editor.

The local editor instructions describe two TSX project kinds: video-editor-next, and craft-reel with FilmCraft edits plus EffectCraft motion graphics. That is a documented possible integration, not a tested current capability. The separate hosted /katana recipe and its session/result tools are present, but reading them starts no session and does not magically add local editor tools.

Likewise there is no callable standalone tool named motion_control, puppeteer or recast in this inventory. Actual motion transfer is still available through Genjutsu and Kling model IDs, as verified above. Do not confuse an absent legacy tool with absence of the supported task, or claim that a legacy Puppeteer interface has been tested.

Production decision

Use Higgsfield first for (1) a 6–8s morning hero with matching still fallback, (2) a restrained mascot jog/wave performance, and (3) a 15s sponsor/event film once the character is selected. Keep the exact approved wordmark and large readable catchphrase as deterministic HTML/vector overlays; avoid asking a video model to preserve small logo text across every frame. Preserve all existing photographic directions and add new takes to the creative warehouse.

The current catalog returned three shared free Genjutsu attempts limited to 480p/720p and 30s, plus 35 AI Influencer sheet attempts. These account-specific counts may change. They were not consumed and do not authorize a generation. A paid model's exact cost requires a current quote with actual duration, resolution, refs and billing mode; no speculative credit estimate is given here. A model being listed or a quote succeeding does not prove generation readiness.

Main pitfalls: anatomy/identity drift, false seamless-loop assumptions, imperfect background extraction, generated text/logo warping, higher webpage bandwidth, autoplay/reduced-motion needs and unverified local editor availability. No output-quality claim was made because no generation was requested or run.
