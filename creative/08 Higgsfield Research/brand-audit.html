Higgsfield image, character and brand audit

Checked 17 October 2026. Read-only tool discovery and first-party web research. No generation, uploads, brand/profile creation or credit spend.

The strongest uses for this project

  1. AutoSprite can animate the existing five animal drawings for the sponsor game. The live model accepts one character image and returns a PNG sprite sheet, with idle, walk, run, jump and custom gestures. This is directly useful for comparing playable mascots. It does not create a Rive rig or .riv file; app code still controls interaction.
  2. Reference-led image generation and outpainting can improve the track/meadow heroes. Use the existing morning-track and midsummer images as references; direct real sunlight, brick-orange shoes, a runner with attitude and space for the headline. Preserve originals. Keep the approved SVG logo and exact headline as HTML/overlays.
  3. Reusable Elements can anchor the chosen mascot, a meadow-track environment and sponsor props across future images/clips. This is a reference system, not a guarantee of identical pixels, anatomy or an editable rig.
  4. Recraft vector/utility-vector can explore the requested running drawings. It exposes palette controls and vector-oriented variants. Current connector has no reference-image input for this model, so it is weaker for extending an approved mascot faithfully. Verify actual file output and layers before promising editable SVG.
  5. Marketing/Ads Studio could help with sponsor recruitment graphics and event social content later. Many templates are too busy, commercial or colour-blocked for the user's understated morning website direction. Do not let these templates set the art direction.

These are recommendations based on discovered capabilities, not output-quality claims.

Four character systems

Elements: reusable characters, environments and props created from confirmed images; only completed elements are usable. Supported by a specific subset of models. Current tool guidance lists Nano Banana Pro/2, GPT Image 2, Seedream 4.5/5 Lite and Cinema Studio Image 2.5 for images, and Cinema Studio Video 2/3, Seedance 2.0 and Kling 3.0 for video. Kling 3.0 additionally needs a start image. Check compatibility again before generation because the guidance and newer model catalog may differ. Recommended project pattern: approved mascot sheet as character, meadow-track environment separately, sponsor object as prop.

Soul ID: already-trained identities can be read and passed to matching Soul/Soul 2/Soul Cinema models. No training tool is exposed here. Website photo-based training exists, but that does not make it executable in this chat. A Reference Element ID is not a Soul ID. Character training website. Official guidance recommends separate identity anchors to stop multiple characters blending. Consistency guide.

AI Influencer Builder: creates character sheets with human and animal traits. Current tiers are human normal/bold/extreme plus insects, frogs, cats, dogs, capybaras and birds. Controls include build, proportions, sporty/retro/streetstyle, hair and accessories. Prepare accepts one identity reference and up to three style/item references, returns design settings and a quote, and generation is separate. Saved settings can be read back.

Project mismatch: hare, fox, raccoon, otter and deer are not selectable current animal tiers. Ordinary reference generation can address them; do not force a hare through a cat/capybara mode. The public API confirms human/animal sheets and warns that selection seeds do not guarantee exact image pixels. Its API dollar pricing is separate from connector credits. AI Influencer API.

AutoSprite: one approved image becomes animation sheets. App code can select idle/run/jump/celebrate on pointer, action or score events. It is a useful game asset route. Rive remains preferable for editable vector limbs, scalable curves, cursor-following pupils and continuous parameter blending.

Marketing Studio Product Shot model currently exposes product_shots, product_shots_people, poster, ads and marketplace. Brand kits can carry name, exact logo, colours, fonts, tone and imagery; a job snapshots the kit when it starts. This is metadata, not a new visual-identity design system.

The public website offers editable Posters via Layers, but no general Layers-editing tool was exposed. Current Ads Studio tools do not expose editing/variation controls and direct these to its website. No automatic Meta/Google publishing tool was discovered.

Ads Studio can quote an event/service prompt without a physical product. Quotes spend nothing; generation uses an exact approved allocation and stable idempotency key. Batch ratios: 1:1, 9:16, 16:9, 3:4; no 4:5. A kit only shapes that brand's own products. Official Ads Studio guide.

Availability gap: DTC Ads model ms_image requires style selection through show_marketing_studio(type=image_style), but that exact tool is absent. marketing_list_ad_formats exists; it has not been proven to satisfy the older model contract. Do not call the whole catalog proven executable.

Presets and production workflows

Gallery examples: Wheatpaste Wall, Halftone Street Collage, Music Zine Collage, Continuous Line Botanical, Golden Dew, Slatted Light Breakfast and Slow ambient were found by name. They are not visually reviewed or approved. Other templates are colour-blocked/pastel and conflict with the brief.

Named recipes: hero shot, flatlay, gym bag, weekend carry, moodboard, signature frame, reel cover, sunrise pass, texture track, push-in, pull-back, product spin and others. Mostly product workflows: Hero Shot means a product advertising still, not automatically a runner homepage hero.

UGC: six profiles: review, product, unboxing, try-on, tutorial and website. Website uses real page captures with a presenter. Can deliver stitched video and optional captions/post package through a multi-stage generation/assembly pipeline. Good later for a real organiser/runner explaining the event. Synthetic attendee testimonials would be a poor application.

Faceless: Explainer, History, Kids, Picture Story, Fairy Tale & Myth. Narrator-led animation, narrated stills and a separate kids song branch. The 22 looks include Hand Drawn, Whiteboard Doodle, Mixed Media, Paper collage, Poster Vector, Watercolor Chronicle, Claymotion and Fluffy Toy. Could help with “run, meet, build” instructions; frequent cuts/narration make it a weaker quiet-hero route.

Ad Multiplier: edits an existing 4–30 second clip into ordered variants: replace/add/remove, clothing, backgrounds and selected text; also recreate and hook/CTA branches. Edit workflow aims to preserve motion/timing and restore source audio with verification. Useful later for variations of real morning-run footage, not necessary for initial hero art. Preservation requires perceptual QA.

These workflows were resolved read-only, not activated. They require explicit command selection before production. Generation, sandbox, upload and wait tools exist; end-to-end runtime/model availability was not preflighted.

Recommendation from scratch

  • Website: reference editing/outpaint, exact approved SVG, readable HTML “Good ideas need fresh air”.
  • Mascot: approve character sheet, compare sprite run/jump quality across all five if useful, then deliberately choose native Rive or a sprite-based game.
  • Sponsor content: restrained original scene, separately composited approved sponsor logo. Use ad templates after the visual direction is settled.
  • Keep all earlier studies accessible. Preserve the exact Running / Hackathon wordmark; never replace it with the prohibited slashed abbreviation or add edition text.

Catalog availability does not prove output quality, licensing clearance, identity consistency or .riv generation. Quote chosen settings live; website subscription credits, API dollar prices and account allowances are different.
