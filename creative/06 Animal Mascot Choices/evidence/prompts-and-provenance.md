# Five animal mascot directions

Generated separately with the built-in imagegen tool, using the earlier original native hare as a style reference. These are static concept illustrations for choosing an animal, not five native Rive rigs. The earlier live hare game and editable source are unchanged.

The five directions are **hare, fox, raccoon, otter and deer**. Shared running kit: forest singlet and shorts, cream trim, brick-orange shoes. Each source PNG is preserved unchanged. Display WebP derivatives only trim transparent margins, resize and add transparent padding to compare the silhouettes at consistent height; no character pixels were repainted.

The illustrated hare is a fresh concept, distinct from the existing live vector rig. The deer has stylized spots; the otter uses a taller, more upright body than the initial squat brief. Rendering depth varies slightly across the five. These are deliberate options for visual review before a chosen direction is redrawn and animated.
