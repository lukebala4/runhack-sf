Run Hack20 handwritten logos.

No digital, no modern. Every logo here is lettered by hand: marker, chalk, ballpoint, brush, pencil, spray paint, a fountain-pen signature, copperplate.

They're logos, not posters. Each one is a single mark on a plain background, so you can judge it as a brand. Click to see it bigger, and star the ones you like.

the rule

Every letter should look like a person made it. Lines wobble, ink bleeds a little, and strokes aren't perfect.

the tools

Marker · chalk · ballpoint · pencil · brush · spray can · rubber stamp · thread · nib pen.

the palette

Paper cream, ink black, ballpoint blue, pen red, chalk white, mint and a little gold.
